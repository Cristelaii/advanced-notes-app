# 📒Advanced Notes App
A modern & responsive Notes application built with HTML, CSS, and JavaScript featuring CRUD operations, search, pinning, favorites, and Local Storage.

## Features

✅ Create Notes
✅ Edit Notes
✅ Delete Notes
✅ Pin Notes
✅ Favorite Notes
✅ Search Notes
✅ Local Storage
✅ Statistics Dashboard


## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
